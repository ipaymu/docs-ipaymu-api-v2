Selamat datang di dokumentasi **iPaymu API v2**. API ini memungkinkan Anda untuk mengintegrasikan layanan payment gateway iPaymu ke dalam aplikasi Anda.

## Base URLs

- **Production/Live**: `https://my.ipaymu.com`
- **Development/Sandbox**: `https://sandbox.ipaymu.com`

<Callout type="warn" title="Catatan Penting">
  * **VA (Virtual Account)** dan **API Key** dapat ditemukan di menu **Integrasi** pada dashboard
  iPaymu Anda. * VA dan API Key untuk mode **Sandbox/Development** **berbeda** dengan mode
  **Production/Live**. * Jika Anda mengalami kendala integrasi, silakan hubungi
  [support@ipaymu.com](mailto:support@ipaymu.com) atau via WhatsApp [di
  sini](https://wa.link/p8vnr7).
</Callout>

## Autentikasi

iPaymu API v2 menggunakan **autentikasi berbasis Signature**. Setiap request harus menyertakan header berikut:

| Header | Tipe | Contoh | Deskripsi |
| :----- | :--- | :----- | :-------- |
| `va` | `string` | `YOUR_VA` | Nomor Virtual Account dari menu Integrasi [Production](https://my.ipaymu.com/integration) atau [Sandbox](https://sandbox.ipaymu.com/integration). Gunakan VA sesuai environment request. |
| `signature` | `string` (64 karakter heksadesimal) | `GENERATED_SIGNATURE` | Hasil HMAC-SHA256 yang dibuat untuk request ini memakai API Key dari menu Integrasi [Production](https://my.ipaymu.com/integration) atau [Sandbox](https://sandbox.ipaymu.com/integration). API Key bukan nilai header ini. Lihat [Pembuatan Signature](/id/docs/signature). |
| `timestamp` | `string` (14 digit) | `20260102153045` | Waktu request dalam format `YYYYMMDDHHmmss` (2 Januari 2026 pukul 15:30:45). Ikuti panduan endpoint jika mensyaratkan ISO 8601. |
