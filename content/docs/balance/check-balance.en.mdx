Check your current iPaymu merchant balance.

## Request Headers

<ApiRequestHeaders lang="en" />

## Request Body

| Parameter | Type   | Required | Description     |
| :-------- | :----- | :------- | :-------------- |
| `account` | string | Yes      | Your iPaymu VA. |

## Example Request

```json
{
  "account": "YOUR_IPAYMU_VA"
}
```

## Example Response

```json
{
  "Status": 200,
  "Data": {
    "Va": "YOUR_IPAYMU_VA",
    "MerchantBalance": "1500000",
    "MemberBalance": "0"
  },
  "Message": "success"
}
```
